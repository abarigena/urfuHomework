# Обработка списка студентов

Консольное приложение для итогового задания по Java. Реализован **базовый уровень**: ввод вручную и загрузка CSV, проверка данных, хранение объектов в `List<Student>`, обработка через Stream API.

## Требования

- JDK 17 или новее.
- Внешние библиотеки не требуются.

## Запуск

Из папки `student-manager` выполните в PowerShell:

```powershell
javac -encoding UTF-8 -d out src/main/java/ru/urfu/studentmanager/*.java
java -cp out ru.urfu.studentmanager.Main
```

## Меню

- `1` — добавить одного студента вручную;
- `2` — загрузить строки из CSV-файла;
- `3` — отфильтровать студентов со средним баллом от 60, преобразовать записи через `map()` и вывести по возрастанию среднего балла;
- `4` — показать весь список;
- `0` — завершить работу.

Средний балл должен быть конечным числом от 0 до 100 включительно. Имя и номер зачётной книжки не могут быть пустыми.

## Формат CSV

Одна запись на строку: `ФИО,среднийБалл,номерЗачётнойКнижки`. Первая строка с заголовком необязательна. Поля разделяются запятыми; запятые внутри полей не поддерживаются. Некорректные строки выводятся с номером строки, остальные записи продолжают загружаться.

Пример файла находится в `data/students.csv`. В меню выберите `2` и укажите путь, например `data/students.csv`.
