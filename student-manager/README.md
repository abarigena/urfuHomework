# Обработка списка студентов

Консольное приложение на Java для итогового задания по дисциплине «Специализированные инструменты прикладного программирования». Выполнен **базовый уровень**.

Предметная область — студент с полями: ФИО, средний балл, номер зачётной книжки.

## Запуск

Нужен JDK 17 или новее, внешние библиотеки не используются. Из папки `student-manager`:

```bash
javac -encoding UTF-8 -d out src/main/java/ru/urfu/studentmanager/*.java
java -cp out ru.urfu.studentmanager.Main
```

## Меню

| Пункт | Действие |
|-------|----------|
| `1` | Добавить студента вручную |
| `2` | Загрузить студентов из CSV-файла |
| `3` | Обработать данные: студенты с баллом от 60, по возрастанию балла |
| `4` | Показать всех студентов |
| `0` | Выход |

Программа работает в цикле, пока не выбран пункт «Выход».

## Структура

| Файл | Назначение |
|------|------------|
| `Main.java` | Точка входа, создаёт `Scanner` и запускает меню |
| `ConsoleApp.java` | Консольное меню, ввод данных и вывод результатов |
| `Student.java` | Класс предметной области (record) с проверкой полей |
| `StudentService.java` | Хранение в `List<Student>`, загрузка CSV, обработка через Stream API |

## Как выполнены требования

- **Валидация.** ФИО и номер зачётной книжки не пустые, средний балл — число от 0 до 100 (дробную часть можно писать через точку или запятую), номер зачётной книжки не повторяется.
- **Исключения.** Ошибки ввода не прерывают программу: выводится сообщение, и меню показывается снова. При чтении файла обрабатываются отсутствующий файл, неверная кодировка и прочие ошибки ввода-вывода.
- **Файлы.** Чтение CSV через `try-with-resources`. Некорректные строки пропускаются с указанием номера строки и причины, остальные загружаются.
- **Stream API** (пункт меню `3`): `filter` — балл не ниже 60, `sorted` — по среднему баллу, `map` — преобразование студента в строку отчёта, затем вывод в консоль.

## Формат CSV

Кодировка UTF-8, одна запись на строку: `ФИО,средний балл,номер зачётной книжки`. Строка заголовка необязательна.

В папке `data` есть два примера:

- `students.csv` — корректные данные;
- `students-with-errors.csv` — файл с ошибками, на котором видно, как работает проверка.
